Engine
Tsubasa uses the FastFlowLM engine installed on this PC (port 52625) and the models you added with flm pull; it never downloads models itself. One model is loaded at a time; switching takes 15–40 s and affects other AI apps that share the engine.

Privacy & data
Everything stays on this PC. Tsubasa listens only on 127.0.0.1, sends no telemetry and checks no updates.
Chats, settings, the Library index and workspace files are stored unencrypted in %LOCALAPPDATA%\Tsubasa. Close Tsubasa before copying that folder as a backup.
With “Files on this PC” Tsubasa can read and change your files and folders, except Windows, Program Files, ProgramData, AppData and key folders (.ssh and similar). Every file it reads or writes asks you first, and writes show the exact change.
In Code mode Tsubasa checks each command on this PC first. Anything that changes something waits for you to press Run, and commands that delete or stop things need a second click. A command that needs administrator rights always asks you here first, then Windows asks too; it runs in a separate administrator PowerShell that closes when the command ends, and its output comes back to Tsubasa.
